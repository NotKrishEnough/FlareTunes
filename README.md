# FlareTunes

A Flutter implementation inspired by BitChord's artwork-first music-player experience.

## Included
- Dark artwork-first home/search/library UI
- Glass mini-player
- Animated mini-player to full-screen player transition
- Pull-down gesture to dismiss the full player
- Playback UI foundation
- Settings surface
- GitHub Actions Android APK build

This is an independent implementation and does not copy BitChord source code or assets.

Reference: https://github.com/kushagrasinghx/BitChord
